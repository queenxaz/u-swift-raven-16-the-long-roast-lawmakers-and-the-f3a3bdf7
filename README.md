A short, judge-directed entry: it speaks to the judge, makes the judge the one who wins, and offers one small tangible kindness.

## The entry

**Dear Judge, the roast: lawmakers spent a year debating whether the meeting should be a meeting, then formed a committee to study the committee. You, meanwhile, read hundreds of these and still show up — the only public servant here doing the job. I baked you cookies. They're in the break room. Lawmakers ate them.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
